# scores/ —— 放你自己的乐谱

这个目录是留给你放**自己创作或已获授权的**乐谱的。仓库里默认为空。

## 用法

1. 在这里新建一个 `.txt` 文件，文件名就是曲名，例如 `我的第一首曲子.txt`
2. 按乐谱语法书写（见下）
3. 打开工作台 `../editor.html`，点「📂 打开乐谱文件」选它，就能试听
4. 想导出 MIDI / JSON，在工作台点对应按钮；或命令行：

   ```bash
   cd ../tools
   node build-song.js "我的第一首曲子"
   ```

   会在本目录生成 `.mid`（MuseScore 可打开）和 `.midi.json`（可拖进演奏台）。

## 语法速查

```text
title 我的第一首曲子
bpm 100
time 4/4

右手:
  C4 D4 E4 F4 | G4 A4 B4 C5 |
  C5 B4 A4 G4 | F4 E4 D4 C4 |

左手:
  [C3 E3 G3]:4 | [F3 A3 C4]:4 |
  [G3 B3 D4]:4 | [C3 E3 G3]:4 |
```

| 写法 | 含义 |
|---|---|
| `C4` | 音符（C4 = 中央 C）；`C#4` / `Bb3` 表示升降 |
| `C4:2` | 时值 2 拍；也可用 `:w` `:h` `:q` `:e` `:s` |
| `[C4 E4 G4]:2` | 和弦 |
| `r` | 休止符 |
| `\|` | 小节线（同时用于拍数校验） |
| `名字:` | 轨道名；**同名 = 接着写**，方便分乐段 |
| `# 注释` | 会被忽略 |

> ⚠️ **请不要把别人的版权作品提交到这个仓库**（包括乐谱、MIDI、录音）。
> 练习用的扒谱请留在本地 —— `.gitignore` 默认已经忽略了本目录下的所有文件。

## 目录约定

`.gitignore` 里配置为：忽略 `scores/*`，只保留本 README。
如果你想分享自己的原创作品，可以在 `.gitignore` 里加例外，例如：

```
!scores/我的原创曲子.txt
```
