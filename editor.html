2 · 语法速查

怎么写出音符（点击展开/收起）
C4 D4 E4白键音，一拍一个（C4 就是中央 C）
C#4 Bb3升号用 #，降号用 b
C5 C3数字是八度，越大越高
C4:2时值 = 2 拍（半音符）
:w :h :q :e :s全 / 半 / 四分 / 八分 / 十六分音符
[C4 E4 G4]:2和弦：三个音一起弹，一起持续 2 拍
r 或 -休止符（不发声，但占时间）
C4 C4 | G4 G4| 是小节线，只帮助你看，不影响发声
主旋律:以冒号结尾的行 = 新开一条轨道；写多条轨道就是多声部
bpm 100设置速度
title 我的曲子设置曲名
time 3/4设置拍号（会用来检查每小节拍数）
# 注释以 # 或 // 开头的内容会被忽略
提示：每行结尾会自动当作一次小节检查，写错拍数会在下面给出黄色提醒。
