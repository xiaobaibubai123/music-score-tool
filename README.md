# Web 电子乐谱工具

用文字写乐谱，立刻听到效果 —— 纯前端的在线乐谱工具，零后端、零构建、可离线运行。

```
写谱  →  ▶ 试听  →  改  →  试听  →  导出 .mid / .mp3 / .json
弹一遍  →  ⏹ 结束  →  自动变成乐谱  →  （回到上面那条）
```

## 这是什么

**两个页面**，互相链接，共用同一份音源和解析器：

**1. 乐谱工作台**（`index.html`）——左边写谱、右边试听：

| 能干什么 | 说明 |
|---|---|
| ✍️ **写谱** | 用文字写乐谱，语法错误带行号可点击跳转，每小节拍数自动校验 |
| ▶️ **试听** | 即时合成播放，支持循环、节拍器、变速；下方钢琴卷帘带播放光标 |
| 📂 **打开** | `.txt` 乐谱文本直接打开；**`.mid` / `.midi` / `.json` 会转成可编辑的乐谱文本** |
| ⬇️ **导出** | `.mid`（MuseScore / DAW 可用）、`.mp3`（浏览器内编码）、`.json`（可再次导入） |

**2. 演奏录音页**（`record.html`）——不会写谱也行，自己弹：

| 能干什么 | 说明 |
|---|---|
| 🎹 **自己弹** | 一次显示一组琴键（13 键，够宽好点），上面标着"当前音区 C4 组"；鼠标点 / 电脑键盘弹 / 手机上直接按 |
| ⏺ **开始 / ⏸ 暂停 / ▶ 继续 / ⏹ 结束** | 暂停期间弹的音不会被录，**暂停的时长也不会算进乐谱** |
| 🔁 **自动变成乐谱** | 结束的那一刻，按你设定的速度/拍号/量化网格生成乐谱脚本，可直接下载或丢进工作台试听 |
| ⌨ **键位随便改** | 面板里点着改（**冲突键位标红**）；也能编辑 `config/keymap.json` 或导入自己的键位 JSON |
| 🔊 **回放我弹的** | 不用生成脚本就能重听一遍刚弹的东西 |
| ✂️ **改错** | 「撤销上一个音」「清空重录」，生成前还能改速度和量化精度 |

> 录音是**记录按键时间**，不是录麦克风 —— 所以没有环境噪音、不需要授权，
> 音色和最终导出的 MP3 完全一致。

## 特性

- **真实钢琴音色**：内置 Salamander Grand Piano 采样（30 个 mp3，覆盖 A0–C8），
  拿不到采样时自动退回内置合成器，功能不受影响
- **纯前端**：没有后端、没有数据库、没有构建步骤。上传几个文件就能用
- **零外部依赖**：Tone.js / @tonejs/midi / lamejs / 钢琴采样全部本地化在 `vendor/`，断网也能跑
- **不依赖 CDN**：适合自部署和内网使用
- **嵌入式**：一条 `<iframe>` 就能放进个人网站的「工具」栏目
- **导出 MP3**：浏览器里离线渲染 + LAME 编码，服务器零参与
- **支持和弦**：`[C4 E4 G4]:2` 让一只手同时按多个键；不同时值可用多条轨道
- **支持延音**：`~C4:2` 让正在响的音继续响而不重新击键（演奏录音页把手按住不放的音写成这样）
- **支持歌词**：`歌词:` 逐字对齐旋律，播放时高亮当前那个字
- **分轨音量**：`vol 0.55` 单独调某条轨道的响度（伴奏通常要比旋律轻）
- **一键排版**：「🔤 每小节换行」把乐谱整理成一小节一行，像看谱一样
- **语法友好**：错误带行号可点击跳转，小节拍数不对会给黄色提醒

## 乐谱语法

```text
title 我的曲子
bpm 100
time 4/4

主旋律:
  C4 C4 G4 G4 | A4 A4 G4:2 |
  F4 F4 E4 E4 | D4 D4 C4:2 |

低音:
  C3:4 | F3:2 C3:2 |
```

| 写法 | 含义 |
|---|---|
| `C4 D4 E4` | 白键音，一拍一个（C4 = 中央 C） |
| `C#4` / `Bb3` | 升号 `#`，降号 `b` |
| `C4:2` | 时值 = 2 拍 |
| `:w :h :q :e :s` | 全 / 半 / 四分 / 八分 / 十六分音符 |
| `[C4 E4 G4]:2` | 和弦 |
| `~C4:2` | 延续：接着前面那个**还在响**的 C4 再响 2 拍，不重新击键（演奏页按住不放的音） |
| `r` 或 `-` | 休止符 |
| `\|` | 小节线（只作视觉分隔，也用于拍数校验） |
| `主旋律:` | 以冒号结尾 = 轨道名；**同名轨道 = 接着往下写**，方便按乐段分段 |
| `barlines off` | 关掉每小节拍数校验（打开 MIDI 转换出来的谱面会自动加这一行） |
| `vol 0.55` | 写在某条轨道里，单独调这条轨道的音量（0~2，默认 1） |
| `歌词:` | 单独一行，下面逐字写，按顺序对齐**第一条轨道**的音符；一个字唱多个音写 `-` |
| `# 注释` | `#` 或 `//` 开头会被忽略 |

> **一只手想同时按多个键 → 用和弦** `[E4 G4 C5]:2`。
> 想在同一条轨道里写「时值不同的音同时发声」，拆成两条轨道即可 ——
> 每条轨道的计时是独立的，用 `r` 休止符补齐空档。

```
│   ├── parser.js                            乐谱 DSL 解析器
│   ├── recorder.js                          录音→乐谱的量化与排版
│   ├── keymap.js                            键位预设与 JSON 解析
│   └── audio.js                             钢琴音源（两个页面共用）
├── config/
│   └── keymap.json                          ← 想换键盘键位就改这个文件
├── docs/
│   ├── 部署安装.md
│   └── 扒谱指南.md
├── vendor/                                  第三方库（本地化，约 2.2 MB）
│   ├── Tone.js       音频引擎
│   ├── Midi.js       MIDI 解析 / 写入
│   ├── lame.min.js   MP3 编码器（LAME 的 JS 版）
│   └── piano/*.mp3   钢琴采样（30 个，Salamander Grand Piano，CC BY）
├── assets/demo.mid                          内置演示曲
├── serve.js                                 本地静态服务器（含 gzip/br 压缩 + 分级缓存）
├── build-dist.js                            打包成可部署的 dist/
├── scores/                                  放你自己的乐谱（仓库里为空）
└── tools/                                   扒谱辅助 + 自动化测试
    ├── build-song.js                        乐谱文本 → .mid / .json，并做音乐性检查
    ├── transcribe/                          从谱面图片扒谱的辅助脚本
    └── fixtures/                            测试用自制乐谱
```

> 为什么 `index.html` / `record.html` 留在根目录：静态托管要求入口页在根目录，
> 否则 `http://你的域名/` 会 404（得写成 `/src/index.html`）。
> `serve.js` 和 `build-dist.js` 也留在根目录 —— 它们是入口命令（`node serve.js`）。

## 自己弹一首

打开 `record.html`（工作台右上角也有入口），按「⏺ 开始录音」→ 弹 → 按「⏹ 结束并生成乐谱」。

默认键位就是各类「在线钢琴」通用的**主键区排法**，正好一组（C4–C5，13 个键）：

```text
黑键：   W  E     T  Y  U
白键： A  S  D  F  G  H  J  K
       do re mi fa sol la si do
```

**钢琴一次只显示一组**（8 白 + 5 黑），键够宽、点得准；上方有字标着
**「当前音区 C4 组 · 小字一组」**，按 **◀ 降一组 / 升一组 ▶** 换音区 ——
那是把整张键位表整体移调一个八度，**琴键、发声、导出的 JSON 三边始终一致**，
不会出现"看着是 C4、弹出来是 C5"。

想换排法就换预设（还有 DAW / 电钢风格的双排两个八度、单排一个八度），或者自己改。

### 改键位

**① 在页面上点着改**（面板「3 · 键位」）

- 表格里每一行是「音符 → 按键」。点某一行的**按键**，再按一个键，就改绑了（<kbd>Esc</kbd> 取消）
- 点 **✕** 删掉一条；上面选个音符再点「🎯 分配按键」可以给新音加键
- **同一个键绑给两个音会标红** —— 因为按下去只会响其中一个，这种事光看键盘是发现不了的。
  红字会写清是哪个键、哪两个音，并给一个「只保留 C4」这样的一键修复
- 换音区用钢琴上面的 **◀ 降一组 / 升一组 ▶**（等价于整组移调），当前是哪个音区会直接标出来

**② 直接改 `config/keymap.json`**（存盘 + 刷新页面即生效）

JSON 的写法是**音符当 key、按键当 value**：

```json
{
  "name": "我的键位",
  "notes": {
    "C4": "KeyA",       // 按键写 KeyboardEvent.code
    "C#4": "KeyW",
    "D4": "KeyS",
    "62": "KeyX"        // 音符也可以写 MIDI 号
  }
}
```

导出/导入（「⬇ 导出当前键位」「📂 导入键位 JSON」）用的都是这个形状。
（也兼容反过来写的 `{ "KeyA": "C4" }`，靠"key 像音名还是像按键代码"自动判断方向。）

写错了不会静默失效 —— `"KeyA"` 写成 `"keya"`（大小写）、音符写成 `"C99"`（音名解析会算出 MIDI 1200）、
`"Shift"` 这种不存在的 code，都会在面板上给出具体提示，其余写对的键照常能用。

生成的脚本可以直接在工作台里继续改（改错音、加歌词、调左手音量），然后导出 MP3。
