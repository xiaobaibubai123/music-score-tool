# Web 电子乐谱工具

用文字写乐谱，立刻听到效果 —— 纯前端的在线乐谱工具，零后端、零构建、可离线运行。

```
写谱  →  ▶ 试听  →  改  →  试听  →  导出 .mid / .mp3 / .json
```

## 这是什么

两个页面，三种用法：

| 页面 | 文件 | 干什么 |
|---|---|---|
| 🎼 **乐谱工作台** | `editor.html` | 左边用文字写乐谱，右边即时试听；语法错误带行号、每小节拍数自动校验；导出 MIDI / MP3 / JSON |
| 🎹 **演奏台** | `index.html` | 3 个八度可点击钢琴 + 电脑键盘演奏 + 真实 MIDI 键盘接入；拖入 `.mid` / `.json` 自动演奏，带钢琴卷帘和播放光标 |
| 🔗 嵌入说明页 | `embed.html` | 可视化嵌入代码生成器（可嵌进个人网站） |

## 特性

- **纯前端**：没有后端、没有数据库、没有构建步骤。上传几个文件就能用
- **零外部依赖**：Tone.js / @tonejs/midi / lamejs 全部本地化在 `vendor/`，断网也能跑
- **不依赖 CDN**：适合自部署和内网使用
- **嵌入式**：一条 `<iframe>` 就能放进个人网站的「工具」栏目
- **导出 MP3**：浏览器里离线渲染 + LAME 编码，服务器零参与
- **语法友好**：错误带行号可点击跳转，小节拍数不对会给黄色提醒

## 快速开始

```bash
git clone <this-repo>
cd music-score-tool
node serve.js
```

打开 http://localhost:8081/editor.html ，**点一下页面**激活音频，然后按「▶ 试听」。

## 乐谱语法

```text
title 我的曲子
bpm 100
time 4/4

主旋律:
  C4 C4 G4 G4 | A4 A4 G4:2 |
  F4 F4 E4 E4 | D4 D4 C4:2 |

低音:
  C3:4 | F3:2 C3:2 |
```

| 写法 | 含义 |
|---|---|
| `C4 D4 E4` | 白键音，一拍一个（C4 = 中央 C） |
| `C#4` / `Bb3` | 升号 `#`，降号 `b` |
| `C4:2` | 时值 = 2 拍 |
| `:w :h :q :e :s` | 全 / 半 / 四分 / 八分 / 十六分音符 |
| `[C4 E4 G4]:2` | 和弦 |
| `r` 或 `-` | 休止符 |
| `\|` | 小节线（只作视觉分隔，也用于拍数校验） |
| `主旋律:` | 以冒号结尾 = 轨道名；**同名轨道 = 接着往下写**，方便按乐段分段 |
| `# 注释` | `#` 或 `//` 开头会被忽略 |

## 目录结构

```
music-score-tool/
├── index.html / editor.html / embed.html    三个页面
├── vendor/                                  第三方库（本地化）
│   ├── Tone.js       音频引擎
│   ├── Midi.js       MIDI 解析 / 写入
│   └── lame.min.js   MP3 编码器（LAME 的 JS 版）
├── assets/demo.mid                          内置演示曲
├── serve.js                                 本地静态服务器（含 gzip/br 压缩 + 分级缓存）
├── build-dist.js                            打包成可部署的 dist/
├── scores/                                  放你自己的乐谱（仓库里为空）
├── tools/                                   扒谱辅助 + 自动化测试
│   ├── build-song.js                        乐谱文本 → .mid / .json，并做音乐性检查
│   ├── transcribe/                          从谱面图片扒谱的辅助脚本
│   └── fixtures/                            测试用自制乐谱
├── 部署安装.md
└── 扒谱指南.md
```
