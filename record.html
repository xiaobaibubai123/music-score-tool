预设 ⬇ 默认 keymap.json
给 分配按键
一个音配一个键，直接在表格里改：点某一行的按键就能重新录一个键（按 Esc 取消）， 点✕删掉这条。同一个键绑给两个音会标红 —— 那样按下去只会响其中一个， 照着红字提示改掉就行。
想换音区按上面的 ◀ 升 / 降一组 ▶：那是把整张键位表整体移调一个八度 （琴键、发声、导出的 JSON 三边始终一致，不会出现"看着是 C4 弹出来是 C5"）。
JSON 的写法是"音符当 key、按键当 value"，仓库根目录的 keymap.json 改完刷新即生效： {"notes": {"C4": "KeyA", "D4": "KeyS"}}。 按键要写 KeyboardEvent.code（KeyA / Digit1 / Semicolon / ArrowLeft）， 音符写音名 C4 / F#3，也可以写 MIDI 号。
